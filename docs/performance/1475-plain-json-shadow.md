# Plain-JSON N/W shadow metadata

This prospective diagnostic never skips a visit, advances inspected, changes a
charge, moves a guard or alters a queue/visited/memo decision. It provides no
semantic-cache or benchmark acceptance. Existing method/source pins still apply.

The existing eager child traversal can attach a stronger summary to its existing
literal certificate: protocol, node count N, LIFO pending peak W and root-key
count. Publish only after the whole object succeeds, forceElement=false, Plain
induction and unchanged reference-sensitive AND borrow epochs. Missing stronger
child metadata makes the parent's stronger summary unavailable; no second walk,
resolve or depth-only promotion occurs. Old literal readiness/depth caching is
unchanged. Counts saturate at100001, and over-limit summaries are shadow misses.

Plain leaves are null/boolean/finite number or strings not starting '$'. Plain
containers have ordinary prototypes, enumerable own data children, no removed
__proto__ field and dense array keys. All '$' values, skipped elements, cycles,
borrowed readiness and binary/opaque/stream/import provenance are excluded.
Completed valid child summaries can survive a later parent's failure, but that
failed parent cannot publish.

For Object.keys-order children0..k-1, N=1+sum(child.N) and
W=max(k,max_j(j+child.W)). Primitives contribute1/0. This follows actual
Object.entries pushes and reverse LIFO processing; it does not sort keys or
assume text insertion order for integer-like keys.

After the ORIGINAL root width guard, shadow lookups require an exact known
ordinary/null-tag/nonstream object, a completed false-force summary and role
exactly required or component-data. Own flag presence/value and known bounded
fallback ancestry are preserved. Fixed histograms distinguish flag states;
ancestry members, values, names, references and per-object tables are never
persisted. Q+W and inspected+N-1 bounds are hypothetical observations only:
neither inspected nor the actual queue is changed.

Hit/node totals can overlap across ancestors and repeated uses. They are inclusive
upper bounds, not unique objects, saved work or completed skips. Actual logical
inspected exclusions may be unreachable before the unchanged shared work cap:
first constructing an N-node Plain certificate already charges its eager visits.
The preview formula remains explicit for a possible later reviewed optimization;
tests never inject a fake certificate or raise a budget to manufacture that case.

Global framing/sticky E, explicit action failures, all independent typed/root
post-checks, protocol-counter multiplicity, child/outer shared work and active
return-prefix/finally accounting remain unchanged. Only new shadow metadata may
differ in old/new synthetic comparisons. No actual payload is reparsed to test
this feature, and no historical failed capture is requalified.
