# Independently closed eager checks (#1475)

`inspectRequiredFlightBody` has a body-local positive cache for completed structural/eager checks. It does not cache semantic roles, renderability, cancellation classification or negative results. Framing finishes before these checks; raw parsed containers and record provenance remain unchanged throughout traversal.

The key is the exact container object, its actual ordinary model origin ID and `forceElement === true`. Ordinary record dereferences carry their actual ID; outlined projections carry the selected origin, including through aliases. A skipped unforced element cannot satisfy a later forced check. No cache or record identity is shared with another body or embedded response.

A candidate publishes only after its full own-field traversal succeeds and a monotonic borrow epoch stays unchanged. The epoch records actual seen-ID/container shortcuts, active outlined anchors, lazy/promise skips, skipped element tuples, opaque text/streams/binary, removed fields and reuse of the older standalone parent certificate. Those results retain their existing behavior but cannot publish an independent certificate. Unrelated enclosing traversal state alone does not disqualify a candidate. Nested children that finish without consuming a provisional dependency may publish; children borrowing an unfinished ancestor may not.

Original seen/cycle, force, depth and shared-work admission still precede lookup. Each hit pays the actual existing traversal step. Its full transitive depth span must fit the existing depth64 cap and is propagated into **every** active ancestor scope. This propagation also applies to literal and older completed-parent hits. An excluded span falls through to ordinary traversal, which still rejects at depth65. At most100000 positive entries can be published under the existing model-work bound. No body, row, recursion, retention or work limit is increased.

The role-aware semantic queue still runs independently, including required aliases, element types, fallback, collections, opaque/binary roles and explicit action failures. Global Flight E scanning remains before graph traversal. No certificate changes route/Native predicates, scheduling, numeric policy or runtime conditions.

`closedEagerMemo` adds aggregate counters to successful body proofs and existing path/model-limit diagnostics: candidates, completed closures, dependency-free closures, publications, hits, depth/origin/capacity exclusions and fixed borrow-reason counts. It retains no model IDs, keys, values or paths. These counters report actual work; they do not claim runtime improvement.

Registered synthetic tests cover repeated ordinary and outlined references; same-model provisional A/B anchors with late missing siblings in both orders; actual-origin aliases and cross-model cycles; skipped versus forced elements; required type/fallback/Map/Set/iterator roles; composed warm/cold depth64/65; repeated-hit and unique work100001; missing/import/text/binary/prototype/undefined boundaries; global E and explicit action failure. The initial repeated-reference fixture exhausted shared work100001 before the change and completes afterward using fewer actual steps. No real payload was reparsed, no browser/fixture was run, and no historical capture is requalified. A fresh Root-owned runtime observation is still required.
