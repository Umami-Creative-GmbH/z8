## Design and agreed test seams

Calm operational entry: an employee or administrator returns to their organization's work. Identity, allowed method and recoverable prerequisite lead. Existing app typography, primary/muted/card/destructive tokens, fine borders and a four-unit spacing rhythm remain. The signature is the resolved organization's own identity above its allowed methods. Work vocabulary: organization, sign-in domain, intended destination, verification, recovery, trusted device. Colors follow the existing blue action, neutral workspace/card/border and semantic failure roles. No marketing panel, decorative image, new font or new palette. Design feasibility: impact 3 + fit 5 + feasibility 5 + performance 5 − consistency risk 3 = 15.

The implementation brief approves the public seams: assembled LoginFormContent with real controller/TanStack fields/DomainAuthProvider/provider query and real widget wrapper callbacks, substituting only external auth client, browser navigation and Cloudflare adapter transport. Canonical callback, Turnstile, required-SSO and native transport suites cover frozen owners. Tests must not mock useLoginAuth, form state or domain context to prove their behavior. Dummy unit transport values are never real challenge/authentication evidence.
