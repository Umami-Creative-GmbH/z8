## Final capability comparison

All rows in the before-change map remain covered at the same owners and destinations. The form now passes resolved domain branding to `AuthFormWrapper` in both states. It uses F3's actual TanStack field/label/error controls, validates empty/invalid submit and focuses email. Email is retained on transport and server refusal; pending locks input and submit with an immediate native-submit guard and an announced, reduced-motion-compatible progress state. An assembled red/green regression exposed a real token race: the lazy auth-client import could outlive the token captured on submit. Widget callbacks now maintain a current-token ref alongside rendered gating; the actual reset call checks that ref after the import, attaches it on that same request, and never makes a separate CAPTCHA verification call. Expiry during import withholds the request, refresh during import sends the latest token, and failure still resets the widget/token for retry. No Better Auth, rate-limit, domain, redirect, email, schema, password or token-lifecycle owner changed. No account-existence lookup was added to the client.

No standalone auth-shell destinations, preferences, footer or theme/language controls were removed. There is no workspace sidebar, organization switcher or role-based action on this public route.
