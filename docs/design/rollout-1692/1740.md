## Design and tests

Managers compare annual allowance evidence and record approved time away. The direction
is Z8's restrained operational workspace: current year/team first, twelve-month availability
next, comparable allowance records and their actions together. Existing font and theme
tokens remain authoritative. Domain vocabulary: absence days, allowance, policy coverage,
deputy, approved/pending, overdrawn vacation. Blue signals selection; neutral borders
group records; semantic attention/failure tokens retain text. A continuous calendar/record
scope replaces disconnected filters, individual metric boxes and an anonymous icon action.

Preapproved seams: rendered route/component behavior, real public server actions and
disposable PostgreSQL. Component tests cover recovery/draft/lifecycle behavior; real PG
checks cover existing authority and calculations. No approval re-request or owner rewrite.
