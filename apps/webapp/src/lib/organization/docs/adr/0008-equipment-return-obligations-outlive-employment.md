# Equipment return obligations outlive employment

An employee can leave while still holding company property. Required returns remain actionable after departure or deactivation and across a later rehire; they never delay the end of employment or access revocation. This preserves the existing separation between an effective departure and unfinished follow-up, rather than leaving employment or credentials active to enforce a physical return.

A return obligation ends through physical receipt or an owner's or admin's reasoned closure as lost or return waived. These outcomes remain distinct. Returning a physical key or fob does not control whether its access credential is revoked.
