<Callout type="info" title="Public API Not Yet Available">
  Z8 does not offer a public API yet. API keys cannot be used to access Z8 data, and no integration should rely on them.
</Callout>

To move data out of Z8 today, use [Payroll Export](/docs/guide/admin-guide/payroll-export) or [Analytics & Exports](/docs/guide/admin-guide/analytics-and-exports) in the web app.

This page will document API access once the public API is available.
