          Recorded work, one period from clock-in to clock-out, in its current
          state: approved corrections are applied, and raw time entries and
          correction history are not returned. Rejected and deleted work is left
          out. Running work is included with no end.


          Each endpoint is a UTC instant with the UTC offset where it was
          recorded. A break is the time between two consecutive work periods of
          an employee.


          `from` and `to` select periods by their start instant.


          Requires the key scope `time-entries:read`.
